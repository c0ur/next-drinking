# 次の一杯｜キンミヤ ルーレット 🎰🍋

キンミヤ焼酎で作れる「次の一杯」を、ド派手なルーレットで決める iPhone スタンドアロンアプリ。
インストール不要・完全オフライン動作の PWA（Web アプリ）です。

## 特徴

- 🎰 **スロット式ルーレット** — ドラムロール → 減速 → ジャン！で運命の一杯が決定
- ✨ **盛り上がる演出てんこ盛り** — 紙吹雪バースト・画面フラッシュ・ネオンの発光・炭酸の泡が舞う背景・「かんぱーい！」演出
- 🔊 **効果音**（Web Audio でリアルタイム合成、音声ファイル不要）
- 📳 **バイブレーション**（対応端末）
- 🍶 **20 種のキンミヤレシピ** — レモンサワー / ホッピー / 緑茶ハイ / 梅干しサワー / お湯割り など。材料・作り方・「強さ」「炭酸」メーター付き
- 🎚️ **フィルター** — 炭酸あり／なし・強め／軽めで絞り込み
- 🥂 **今日の乾杯カウンター**（端末内に保存）
- 📴 **オフライン対応** — Service Worker でキャッシュ、ホーム画面から全画面起動

## iPhone へのインストール（ホーム画面に追加）

1. このアプリを HTTPS で配信する（下記「公開」参照）
2. **Safari** でそのURLを開く
3. 共有ボタン → **「ホーム画面に追加」**
4. 追加されたアイコンから起動すると、Safari の UI が消えて全画面のスタンドアロンアプリとして動作します

> サウンド・バイブは、最初にボタンをタップした時点で有効になります（iOS の仕様）。

## 公開（ホスティング）

静的ファイルだけなので、任意の静的ホスティングに置くだけで動きます（GitHub Pages / Netlify / Cloudflare Pages など）。
ホーム画面追加とオフライン動作には **HTTPS** が必須です。

### ローカルで試す

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## ファイル構成

```
index.html              アプリ本体（HTML/CSS/JS すべて内包）
manifest.webmanifest    PWA マニフェスト
sw.js                   Service Worker（オフラインキャッシュ）
icons/                  アプリアイコン（PNG）
tools/make_icons.py     アイコン生成スクリプト（Python 標準ライブラリのみ）
```
